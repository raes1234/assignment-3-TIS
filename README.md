Overview
This repository contains notes from Industrial Talk 2 by Ts. Hj. Abdul Alim Bin Abdul Muttalib, Head of Technology and Innovation at Serunai Commerce. The talk focused on project management and system development as key foundations for computer science students.

Key Points
Importance of project management (Waterfall vs. Agile).

System Development Life Cycle (SDLC) and modern Agentic Coding with AI tools.

Academic knowledge vs. industry expectations.

Need for both technical and soft skills.

Reflection
Each member reflected on personal goals for the next four years, including improving technical expertise, adopting applied learning, gaining leadership experience, and developing soft skills.
